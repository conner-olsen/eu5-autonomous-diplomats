Diplomáticos Autónomos / Autonomous Diplomats
===WORKSHOP_DESCRIPTION===

[h1]Resumen:[/h1]
Recupera el sistema de diplomáticos automatizados de EU4 con mejora automática de relaciones y otras funciones.

Requiere [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url].

[h1]Características:[/h1]
[olist]
 [*][b]Mejorar relaciones automáticamente:[/b]
  [list]
   [*][b]Países vecinos:[/b] Mejora las relaciones con naciones limítrofes aleatorias.
   [*][b]Súbditos propios:[/b] Mejora las relaciones con naciones súbditas aleatorias.
   [*][b]Países indignados:[/b] Mejora primero las relaciones con las naciones que tengan el mayor nivel de antagonismo hacia ti.
   [*][b]Aliados:[/b] Mejora las relaciones con naciones aliadas y miembros de ligas defensivas.
   [*][b]Países amenazantes:[/b] Mejora primero las relaciones con las naciones que supongan el mayor nivel de amenaza para ti.
   [*][b]Electores del SIR:[/b] Mejora las relaciones con los electores del Sacro Imperio Romano Germánico. Solo visible para miembros del SIR.
   [*][b]Miembros del SIR:[/b] Mejora las relaciones con los demás miembros del Sacro Imperio Romano Germánico. Solo visible para miembros del SIR.
  [/list]
  [list]
   [*][b]Prioridad de arrastrar para reordenar:[/b] Configura qué categorías reciben diplomáticos primero a través del Community Mod Menu.
   [*][b]Límites de diplomáticos por categoría:[/b] Controla cuántos diplomáticos puede usar cada categoría (0-10).
  [/list]
 [*][b]Interacciones con súbditos:[/b] Realiza acciones de súbditos automáticamente siempre que sea posible.
  [list]
   [*][b]Imponer religión:[/b] Impón tu religión de estado a los súbditos.
   [*][b]Imponer cultura:[/b] Impón tu cultura principal a los súbditos.
  [/list]
 [*][b]Reservas de diplomáticos:[/b] Establece un número mínimo de diplomáticos libres y una ganancia mensual mínima de diplomáticos para mantener en reserva. Las acciones autónomas no bajarán de tus umbrales establecidos.
 [*][b]Seguimiento del progreso:[/b] No volverá a seleccionar como objetivo a países que ya tengan +190 de opinión.
[/olist]

[h1]Problemas conocidos:[/h1]
[list]
 [*]Algunas interacciones diplomáticas no tendrán confirmaciones cuando normalmente las tendrían. Esto es necesario para la cancelación automática, pero buscaré una solución mejor.
[/list]

[h1]Compatibilidad:[/h1]
[list]
 [*]No es compatible con Ironman ni con logros.
 [*]Totalmente compatible con partidas guardadas.
 [*]Debería funcionar con cualquier mod.
 [*]Puedo añadir parches de compatibilidad bajo petición.
[/list]
