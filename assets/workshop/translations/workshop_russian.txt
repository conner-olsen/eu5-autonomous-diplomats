Автономные дипломаты / Autonomous Diplomats
===WORKSHOP_DESCRIPTION===

[h1]Обзор:[/h1]
Возвращает систему автоматизированных дипломатов из EU4 с авто-улучшением отношений и другими функциями.

Требуется [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url].

[h1]Особенности:[/h1]
[olist]
 [*][b]Авто-улучшение отношений:[/b]
  [list]
   [*][b]Соседние страны:[/b] Улучшает отношения со случайными приграничными государствами.
   [*][b]Собственные субъекты:[/b] Улучшает отношения со случайными зависимыми государствами.
   [*][b]Возмущенные страны:[/b] Улучшает отношения со странами, чей антагонизм по отношению к вам составляет не менее 10 (начиная с самых враждебных), и прекращает улучшение, когда их антагонизм падает ниже 5.
   [*][b]Союзники:[/b] Улучшает отношения с союзными государствами и членами оборонительных лиг.
   [*][b]Угрожающие страны:[/b] Улучшает отношения в первую очередь с теми странами, которые представляют для вас наибольшую угрозу.
   [*][b]Лидеры имперских округов СРИ:[/b] Улучшает отношения с лидерами имперских округов Священной Римской империи. Доступно только для членов СРИ.
   [*][b]Курфюрсты СРИ:[/b] Улучшает отношения с курфюрстами Священной Римской империи. Доступно только для членов СРИ.
   [*][b]Члены СРИ:[/b] Улучшает отношения с другими членами Священной Римской империи. Доступно только для членов СРИ.
   [*][b]Владельцы рынков:[/b] Улучшает отношения со странами, владеющими рынком.
   [*][b]Королевства и империи:[/b] Улучшает отношения с королевствами и империями.
   [*][b]Крупнейшие страны:[/b] Улучшает отношения с крупнейшими из открытых стран в пределах вашей дипломатической дистанции, начиная с самых больших.
  [/list]
  [list]
   [*][b]Приоритет перетаскиванием:[/b] Выбирайте, какие категории получают дипломатов первыми, через Community Mod Menu.
   [*][b]Лимиты дипломатов по категориям:[/b] Контролируйте количество дипломатов для каждой категории (от 0 до 10).
  [/list]
 [*][b]Взаимодействие с субъектами:[/b] Автоматически выполняет действия с субъектами при первой возможности.
  [list]
   [*][b]Навязать религию:[/b] Навязывает вашу государственную религию субъектам.
   [*][b]Навязать культуру:[/b] Навязывает вашу основную культуру субъектам.
  [/list]
 [*][b]Резерв дипломатов:[/b] Установите минимальное количество свободных дипломатов и минимальный ежемесячный прирост дипломатов, которые нужно держать в резерве. Автономные действия не будут опускаться ниже заданных порогов.
 [*][b]Лимиты улучшения отношений:[/b] Установите максимальное значение отношений, при достижении которого улучшение прекращается (а текущие действия отменяются), а также максимальный уровень антагонизма, выше которого страны будут игнорироваться.
 [*][b]Блокировка конкретных стран:[/b] Остановите авто-улучшение отношений с выбранной страной с помощью дипломатического действия «Запретить автономное улучшение» (Block Autonomous Improving) и возобновите с помощью «Разрешить автономное улучшение» (Allow Autonomous Improving).
[/olist]
