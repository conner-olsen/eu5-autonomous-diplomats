[h1]Обзор:[/h1]
Возвращает систему автоматических дипломатов из EU4 с функцией автоматического улучшения отношений и другими возможностями.

Требуется [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url].

[h1]Особенности:[/h1]
[olist]
 [*][b]Автоматическое улучшение отношений:[/b]
  [list]
   [*][b]Соседние страны:[/b] Улучшает отношения со случайными приграничными государствами.
   [*][b]Собственные субъекты:[/b] Улучшает отношения со случайными странами-субъектами.
   [*][b]Разгневанные страны:[/b] Улучшает отношения в первую очередь с теми странами, которые настроены наиболее враждебно.
   [*][b]Союзники:[/b] Улучшает отношения с союзными государствами и членами оборонительных лиг.
   [*][b]Угрожающие страны:[/b] Улучшает отношения в первую очередь с теми странами, которые представляют для вас наибольшую угрозу.
   [*][b]Курфюрсты СРИ:[/b] Улучшает отношения с выборщиками Священной Римской империи. Доступно только для членов СРИ.
   [*][b]Члены СРИ:[/b] Улучшает отношения с другими членами Священной Римской империи. Доступно только для членов СРИ.
  [/list]
  [list]
   [*][b]Приоритет перетаскиванием:[/b] Настройте через Community Mod Menu, какие категории получают дипломатов первыми.
   [*][b]Лимиты дипломатов на категорию:[/b] Контролируйте, сколько дипломатов может использовать каждая категория (0-10).
  [/list]
 [*][b]Взаимодействие с субъектами:[/b] Автоматически выполняет действия с субъектами, когда это возможно.
  [list]
   [*][b]Навязать религию:[/b] Навязывает государственную религию вашим субъектам.
   [*][b]Навязать культуру:[/b] Навязывает вашу основную культуру вашим субъектам.
  [/list]
 [*][b]Резервы дипломатов:[/b] Установите минимальное количество свободных дипломатов и минимальный ежемесячный прирост дипломатов для сохранения в резерве. Автономные действия не будут опускаться ниже ваших пороговых значений.
 [*][b]Отслеживание прогресса:[/b] Мод не будет выбирать целями страны, отношения с которыми уже достигли +190.
[/olist]
