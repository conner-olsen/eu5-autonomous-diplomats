[h1]Обзор:[/h1]
Autonomous Diplomats возвращает систему автоматизации дипломатов из EU4. Ваши свободные дипломаты каждый месяц отправляются на улучшение отношений с целевыми странами. Настраивайте приоритетные категории, лимиты дипломатов и резервы через Community Mod Menu — забудьте о микроменеджменте действий по улучшению отношений.

Требуется [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url].

[h1]Особенности:[/h1]
[olist]
 [*][b]Автоматическая отправка дипломатов:[/b] Отправляет свободных дипломатов улучшать отношения с целевыми странами при ежемесячном тике.
 [*][b]7 категорий целей:[/b]
  [list]
   [*][b]Соседние страны:[/b] Улучшает отношения со случайными приграничными государствами.
   [*][b]Собственные субъекты:[/b] Улучшает отношения со случайными зависимыми государствами.
   [*][b]Возмущенные страны:[/b] В первую очередь улучшает отношения со странами, проявляющими к вам наибольшую враждебность.
   [*][b]Союзники:[/b] Улучшает отношения с союзными государствами и членами оборонительных лиг.
   [*][b]Угрожающие страны:[/b] В первую очередь улучшает отношения со странами, представляющими для вас наибольший уровень угрозы.
   [*][b]Курфюрсты СРИ:[/b] Улучшает отношения с выборщиками Священной Римской империи. Видно только для членов СРИ.
   [*][b]Члены СРИ:[/b] Улучшает отношения с другими членами Священной Римской империи. Видно только для членов СРИ.
  [/list]
  [list]
   [*][b]Приоритет перетаскиванием:[/b] Устанавливайте порядок категорий для получения дипломатов через Community Mod Menu.
   [*][b]Лимиты дипломатов на категорию:[/b] Контролируйте, сколько дипломатов может использовать каждая категория (0–10).
  [/list]
 [*][b]Взаимодействие с субъектами:[/b] Автоматически выполняет действия с субъектами, когда это возможно.
  [list]
   [*][b]Навязать религию:[/b] Навязывает вашу государственную религию субъектам.
   [*][b]Навязать культуру:[/b] Навязывает вашу основную культуру субъектам.
  [/list]
 [*][b]Резервы дипломатов:[/b] Установите минимальное количество свободных дипломатов и минимальный ежемесячный прирост дипломатов для сохранения в резерве. Автономные действия не будут нарушать установленные вами пороги.
 [*][b]Отслеживание прогресса:[/b] Отслеживает прогресс улучшения для каждой цели. Не будет выбирать целью страны, отношения с которыми уже достигли +90. Прогресс со временем естественным образом снижается, если дипломаты переназначаются.
[/olist]

[h1]Известные проблемы:[/h1]
[list]
 [*]Мод использует собственное внутреннее отслеживание отправленных дипломатов. Если вы вручную отмените действие по улучшению отношений, мод не обнаружит это мгновенно. Однако со временем он всегда синхронизируется самостоятельно.
[/list]
