Автономные дипломаты / Autonomous Diplomats
===WORKSHOP_DESCRIPTION===

[h1]Обзор:[/h1]
Возвращает систему автоматических дипломатов из EU4 с авто-улучшением отношений и другими функциями.

Требуется [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url].

[h1]Особенности:[/h1]
[olist]
 [*][b]Авто-улучшение отношений:[/b]
  [list]
   [*][b]Соседние страны:[/b] Улучшает отношения со случайными приграничными нациями.
   [*][b]Собственные субъекты:[/b] Улучшает отношения со случайными странами-субъектами.
   [*][b]Разгневанные страны:[/b] Улучшает отношения с нациями, имеющими как минимум 25 единиц антагонизма к вам; в первую очередь с самыми враждебными, и прекращает улучшение, как только их антагонизм падает ниже 5.
   [*][b]Союзники:[/b] Улучшает отношения с союзными нациями и членами оборонительных лиг.
   [*][b]Угрожающие страны:[/b] Улучшает отношения в первую очередь с нациями, которые представляют для вас наибольший уровень угрозы.
   [*][b]Лидеры имперских округов СРИ:[/b] Улучшает отношения с лидерами имперских округов в Священной Римской империи. Видно только для членов СРИ.
   [*][b]Курфюрсты СРИ:[/b] Улучшает отношения с курфюрстами Священной Римской империи. Видно только для членов СРИ.
   [*][b]Члены СРИ:[/b] Улучшает отношения с другими членами Священной Римской империи. Видно только для членов СРИ.
   [*][b]Владельцы рынков:[/b] Улучшает отношения со странами, владеющими рынком.
   [*][b]Королевства и империи:[/b] Улучшает отношения с королевствами и империями.
   [*][b]Крупнейшие нации:[/b] Улучшает отношения с крупнейшими открытыми вами нациями в пределах вашей дипломатической дистанции, начиная с самых больших.
  [/list]
  [list]
   [*][b]Приоритет через перетаскивание:[/b] Установите, какие категории получают дипломатов первыми, через Community Mod Menu.
   [*][b]Лимиты дипломатов на категорию:[/b] Контролируйте, сколько дипломатов может использовать каждая категория (0-10).
  [/list]
 [*][b]Взаимодействие с субъектами:[/b] Автоматически выполняет действия с субъектами при любой возможности.
  [list]
   [*][b]Навязать религию:[/b] Навязывает вашу государственную религию субъектам.
   [*][b]Навязать культуру:[/b] Навязывает вашу основную культуру субъектам.
  [/list]
 [*][b]Авто-подарки:[/b] Добавляйте страны в очередь с помощью дипломатического действия «Начать авто-подарки», и каждой из них будет отправлен максимально возможный подарок по истечении десятилетней перезарядки, что принесет услуги и мнение.
  [list]
   [*][b]Очередь приоритетов:[/b] Изменяйте порядок очереди, чтобы определить, какие страны получат золото и дипломатов первыми; в любой момент можно приостановить или отменить запись.
   [*][b]Золотой запас:[/b] Установите минимальный размер казны. Подарок будет пропущен, если оплата за него опустит казну ниже этого уровня.
  [/list]
 [*][b]Резерв дипломатов:[/b] Установите минимальное количество свободных дипломатов и минимальный ежемесячный прирост дипломатов, которые нужно держать в резерве.
 [*][b]Лимиты улучшения:[/b] Установите максимальное значение отношений, при котором улучшение прекращается и текущие процессы отменяются, а также максимальный антагонизм, выше которого страны будут игнорироваться.
 [*][b]Блокировка конкретных стран:[/b] Прекратите авто-улучшение отношений с выбранной страной, используя дипломатическое действие «Заблокировать авто-улучшение», и возобновите с помощью «Разрешить авто-улучшение».
[/olist]
