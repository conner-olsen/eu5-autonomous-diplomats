[h1]Обзор:[/h1]
Возвращает систему автоматических дипломатов из EU4 с функцией автоматического улучшения отношений и другими возможностями.

Требуется [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url].

[h1]Особенности:[/h1]
[olist]
 [*][b]Автоматическое улучшение отношений:[/b]
  [list]
   [*][b]Соседние страны:[/b] Улучшает отношения со случайными приграничными странами.
   [*][b]Собственные субъекты:[/b] Улучшает отношения со случайными подвластными странами.
   [*][b]Возмущенные страны:[/b] В первую очередь улучшает отношения со странами, имеющими наивысший уровень антагонизма по отношению к вам.
   [*][b]Союзники:[/b] Улучшает отношения с союзными государствами и членами оборонительных лиг.
   [*][b]Угрожающие страны:[/b] В первую очередь улучшает отношения со странами, представляющими для вас наибольшую угрозу.
   [*][b]Лидеры имперских округов СРИ:[/b] Улучшает отношения с лидерами имперских округов Священной Римской империи. Видно только для членов СРИ.
   [*][b]Курфюрсты СРИ:[/b] Улучшает отношения с курфюрстами Священной Римской империи. Видно только для членов СРИ.
   [*][b]Члены СРИ:[/b] Улучшает отношения с другими членами Священной Римской империи. Видно только для членов СРИ.
   [*][b]Владельцы рынков:[/b] Улучшает отношения со странами, владеющими рынком.
   [*][b]Королевства и империи:[/b] Улучшает отношения с королевствами и империями.
  [/list]
  [list]
   [*][b]Приоритет через перетаскивание:[/b] Настройте порядок категорий, по которому будут распределяться дипломаты, через Community Mod Menu.
   [*][b]Лимиты дипломатов на категорию:[/b] Контролируйте, сколько дипломатов может использовать каждая категория (0-10).
  [/list]
 [*][b]Взаимодействие с субъектами:[/b] Автоматически выполняет действия с субъектами при первой возможности.
  [list]
   [*][b]Насаждение религии:[/b] Навязывайте свою государственную религию субъектам.
   [*][b]Насаждение культуры:[/b] Навязывайте свою основную культуру субъектам.
  [/list]
 [*][b]Резерв дипломатов:[/b] Установите минимальное количество свободных дипломатов и минимальный ежемесячный прирост дипломатов для хранения в резерве. Автономные действия не будут опускаться ниже заданных порогов.
 [*][b]Отслеживание прогресса:[/b] Не выбирает повторно страны, отношения с которыми уже достигли +190.
[/olist]
