[h1]Обзор:[/h1]
Возвращает систему автоматических дипломатов из EU4 с функцией авто-улучшения отношений и другими возможностями.

Требуется [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url].

[h1]Особенности:[/h1]
[olist]
 [*][b]Авто-улучшение отношений:[/b]
  [list]
   [*][b]Соседние страны:[/b] Улучшает отношения со случайными приграничными государствами.
   [*][b]Собственные субъекты:[/b] Улучшает отношения со случайными подвластными странами.
   [*][b]Возмущенные страны:[/b] В первую очередь улучшает отношения со странами, имеющими самый высокий уровень антагонизма по отношению к вам.
   [*][b]Союзники:[/b] Улучшает отношения с союзными государствами и членами оборонительных лиг.
   [*][b]Угрожающие страны:[/b] В первую очередь улучшает отношения со странами, представляющими для вас наибольшую угрозу.
   [*][b]Курфюрсты СРИ:[/b] Улучшает отношения с курфюрстами Священной Римской империи. Видно только для членов СРИ.
   [*][b]Члены СРИ:[/b] Улучшает отношения с другими членами Священной Римской империи. Видно только для членов СРИ.
   [*][b]Владельцы рынков:[/b] Улучшает отношения со странами, владеющими рынком.
   [*][b]Королевства+:[/b] Улучшает отношения с королевствами и империями.
  [/list]
  [list]
   [*][b]Приоритет перетаскиванием:[/b] Настройте, какие категории получают дипломатов в первую очередь, через Community Mod Menu.
   [*][b]Лимиты дипломатов на категорию:[/b] Контролируйте, сколько дипломатов может использовать каждая категория (0-10).
  [/list]
 [*][b]Взаимодействие с субъектами:[/b] Автоматически выполняет действия с субъектами, когда это возможно.
  [list]
   [*][b]Навязать религию:[/b] Навязывайте свою государственную религию субъектам.
   [*][b]Навязать культуру:[/b] Навязывайте свою основную культуру субъектам.
  [/list]
 [*][b]Резерв дипломатов:[/b] Установите минимальное количество свободных дипломатов и минимальный ежемесячный прирост дипломатов для хранения в резерве. Автономные действия не будут опускаться ниже ваших пороговых значений.
 [*][b]Отслеживание прогресса:[/b] Система не будет повторно выбирать страны, чье мнение уже достигло +190.
[/olist]
