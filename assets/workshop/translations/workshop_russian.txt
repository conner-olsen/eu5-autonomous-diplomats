[h1]Обзор:[/h1]
Возвращает систему автоматизированных дипломатов из EU4 с автоматическим улучшением отношений и другими функциями.

Требуется [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url].

[h1]Особенности:[/h1]
[olist]
 [*][b]Автоматическое улучшение отношений:[/b]
  [list]
   [*][b]Соседние страны:[/b] Улучшает отношения со случайными приграничными государствами.
   [*][b]Собственные субъекты:[/b] Улучшает отношения со случайными подвластными странами.
   [*][b]Возмущенные страны:[/b] Улучшает отношения в первую очередь с теми странами, которые настроены к вам наиболее враждебно.
   [*][b]Союзники:[/b] Улучшает отношения с союзными государствами и членами оборонительных лиг.
   [*][b]Угрожающие страны:[/b] Улучшает отношения в первую очередь с теми странами, которые представляют для вас наибольшую угрозу.
   [*][b]Лидеры имперских округов СРИ:[/b] Улучшает отношения с лидерами имперских округов Священной Римской империи. Видно только участникам СРИ.
   [*][b]Курфюрсты СРИ:[/b] Улучшает отношения с выборщиками Священной Римской империи. Видно только участникам СРИ.
   [*][b]Члены СРИ:[/b] Улучшает отношения с другими членами Священной Римской империи. Видно только участникам СРИ.
   [*][b]Владельцы рынков:[/b] Улучшает отношения со странами, владеющими рынком.
   [*][b]Королевства и империи:[/b] Улучшает отношения с королевствами и империями.
  [/list]
  [list]
   [*][b]Приоритет через перетаскивание:[/b] Устанавливайте, какие категории получают дипломатов первыми, через Community Mod Menu.
   [*][b]Лимиты дипломатов по категориям:[/b] Контролируйте, сколько дипломатов может использовать каждая категория (0-10).
  [/list]
 [*][b]Взаимодействие с субъектами:[/b] Автоматически выполняет действия с субъектами при любой возможности.
  [list]
   [*][b]Навязать религию:[/b] Навязывает вашу государственную религию субъектам.
   [*][b]Навязать культуру:[/b] Навязывает вашу основную культуру субъектам.
  [/list]
 [*][b]Резерв дипломатов:[/b] Установите минимальное количество свободных дипломатов и минимальный ежемесячный прирост дипломатов для хранения в резерве. Автономные действия не будут опускаться ниже заданных порогов.
 [*][b]Отслеживание прогресса:[/b] Не выбирает повторно страны, отношения с которыми уже достигли +190.
[/olist]

[list]
 [*]В некоторых дипломатических взаимодействиях не будет подтверждений там, где они должны быть. Это необходимо для автоотмены, но я поищу лучшее решение.
[/list]
