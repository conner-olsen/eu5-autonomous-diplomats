[h1]Обзор:[/h1]
Возвращает систему автоматизированных дипломатов из EU4 с авто-улучшением отношений и другими функциями.

Требует [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url].

[h1]Особенности:[/h1]
[olist]
 [*][b]Авто-улучшение отношений:[/b]
  [list]
   [*][b]Соседние страны:[/b] Улучшает отношения со случайными приграничными странами.
   [*][b]Собственные субъекты:[/b] Улучшает отношения со случайными странами-субъектами.
   [*][b]Разгневанные страны:[/b] Улучшает отношения в первую очередь со странами, имеющими самый высокий уровень антагонизма по отношению к вам.
   [*][b]Союзники:[/b] Улучшает отношения с союзными странами и членами оборонительных лиг.
   [*][b]Угрожающие страны:[/b] Улучшает отношения в первую очередь со странами, представляющими для вас наибольший уровень угрозы.
   [*][b]Курфюрсты СРИ:[/b] Улучшает отношения с курфюрстами Священной Римской империи. Видно только для членов СРИ.
   [*][b]Члены СРИ:[/b] Улучшает отношения с другими членами Священной Римской империи. Видно только для членов СРИ.
  [/list]
  [list]
   [*][b]Приоритет через перетаскивание:[/b] Устанавливайте, какие категории получают дипломатов первыми через Community Mod Menu.
   [*][b]Лимиты дипломатов на категорию:[/b] Управляйте тем, сколько дипломатов может использовать каждая категория (0-10).
  [/list]
 [*][b]Взаимодействие с субъектами:[/b] Автоматически выполняет действия с субъектами при любой возможности.
  [list]
   [*][b]Навязать религию:[/b] Навязывайте свою государственную религию субъектам.
   [*][b]Навязать культуру:[/b] Навязывайте свою основную культуру субъектам.
  [/list]
 [*][b]Резерв дипломатов:[/b] Установите минимальное количество свободных дипломатов и минимальный ежемесячный прирост дипломатов для хранения в резерве. Автономные действия не будут опускаться ниже ваших пороговых значений.
 [*][b]Отслеживание прогресса:[/b] Не будет выбирать в качестве цели страны, мнение которых уже достигло +190.
[/olist]
